# Book Recommender System

A machine learning–based recommendation engine that suggests books to users based on popularity, collaborative filtering, and content similarity.
# Features
- Popular books section (based on ratings and number of votes)
- Content-based similarity using cosine similarity
- Interactive web interface built with Flask
- Preprocessed datasets stored in `.pkl` files for fast loading
# Tech Stack
- **Python** (Flask, Pandas, NumPy, Scikit-learn)
- **HTML/CSS** (templates for UI)
- **Pickle** (for saving trained models and data)
- **PyCharm** IDE for development
